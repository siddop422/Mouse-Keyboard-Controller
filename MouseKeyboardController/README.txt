MOUSE + KEYBOARD CONTROLLER v1.0.0 — PORTABLE WINDOWS APP

GET STARTED
1. Extract the downloaded ZIP to a normal folder.
2. Double-click START_CONTROLLER.cmd.
3. Click Choose .EXE... and select the application's executable.
4. Click Launch selected app.
5. Keep the controller window open while using the selected app.

DEFAULT CONTROLS
Arrow keys          Move mouse pointer
Shift + arrows      Move faster
Enter / Space       Left-click
Backspace           Right-click
Numpad 0            Hold left mouse button to drag
Numpad Decimal      Release drag
F6                  Show controls help
F7                  Toggle controller on/off

REQUIREMENTS
Uses Windows PowerShell, .NET Windows Forms, and Win32 input APIs.
No installer or third-party dependency is intended.

NOTES
This is a keyboard-to-mouse helper, not a native patch to the selected app.
Some full-screen games or applications may reject synthetic input.
If the target runs as administrator, Windows may require matching privileges.
Only launch applications you trust. Review the PowerShell source if desired.
