# Changelog

Notable project changes are recorded here.

## [1.0.0] - 2026-10-20

Initial public repository release.

### Added
- Windows Forms GUI for selecting a local executable.
- Launch and stop controls for the process started by the controller.
- Arrow-key pointer movement and Shift-assisted faster movement.
- Enter and Space left-click actions.
- Backspace right-click action.
- Numpad drag hold/release controls.
- F6 controls help and F7 input enable/disable toggle.
- Portable CMD launcher and setup notes.
- Project documentation and MIT license.

### Known limitations
- Customizable key bindings and sensitivity controls are not included in this release.
- Pointer movement is limited to the primary display.
- Compatibility varies with full-screen games, anti-cheat software, elevated processes, and custom input systems.
